# StudyFlow

StudyFlow es una aplicación destinada a estudiantes que necesiten organizar sus asignaturas, tareas, exámenes y sesiones de estudio.

## Objetivo

Ayudar a los estudiantes a organizar sus actividades académicas, consultar sus tareas pendientes, planificar el tiempo de estudio y llevar un seguimiento de su progreso.

Cada usuario podrá acceder a su propia información mediante un inicio de sesión sencillo.

## Tecnologías previstas

- Python 3
- MySQL
- Flask
- HTML y CSS
- Git y GitHub
